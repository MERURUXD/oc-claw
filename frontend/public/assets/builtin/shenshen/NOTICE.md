# Third-party asset notice: Shenshen videos

This builtin bundle contains the complete 106-video Shenshen animation catalog from [`PC2005-cloud/dsh-pet`](https://github.com/PC2005-cloud/dsh-pet/tree/814b0e47812dfd51dbc2df4ca272b57403c5e9cd/dsh-pet/assets/webm), pinned to tag `v0.2.8` and commit `814b0e47812dfd51dbc2df4ca272b57403c5e9cd`. The files total **54,376,328 bytes**. Every bundled WebM is recorded with its upstream Git blob ID, local SHA-256, and byte size in the [Shenshen animation catalog](../../../../src/lib/shenshen-animation-catalog.json); the catalog is checked against the directory by automated tests.

The original character is OC “溟月”, by artist 上善无形. The project owner confirmed that all 106 videos are authorized for use and distribution with this repository. Upstream asset conditions still apply: its README says **“素材（动画/提示词/源视频）：允许开源使用，禁止商用”** (open-source use is allowed; commercial use is prohibited). For derivative, modified, or reskinned works, the README requires the original GitHub repository address to accompany introductions, displays, and distributions of that work. Keep this notice and the upstream repository attribution with redistributed copies.

The pinned upstream `LICENSE` is MIT for the upstream code. It does not grant commercial rights to these video assets and does not replace their asset-specific conditions. The term “CC BY-NC-SA-like” appeared in a downstream notice but is not a formal license identifier for this catalog.
